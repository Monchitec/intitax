# Módulo del Portal Intitax

Esta carpeta alojará los componentes y herramientas del Portal de Clientes / Gestión:
- `layout/`: Sidebar, cabecera de sesión y navegación privada.
- `citas/`: Calendario interactivo, selector de horarios y confirmación.
- `documentos/`: Subida y administración de archivos W-2, 1040, etc.
